# Budget Buddy 3.0 Stable — two Buddies, one offline mission

Budster packed two backpacks for this release. Pick the one that fits your phone and your pace:

- **Budget-Buddy-OCR-v3.0-stable.apk** reads receipt text on-device and suggests the merchant, date, total, items, and category for faster entry.
- **Budget-Buddy-No-OCR-v3.0-stable.apk** keeps entry manual and leaves out the recognition model for a smaller installation.

Both are called **Budget Buddy** after installation, use separate app identities, and can live happily side by side.

## The 3.0 glow-up

- Added a complete hands-on tutorial across the real Home, Budget, Transaction, OCR, Analytics, and Achievement screens.
- Added offline receipt OCR, local parsing and classification, an optional review step, stable OCR tags, and a renameable OCR label to the OCR edition.
- Added detailed transaction views, clearer history filters, safer receipt copies, and cleanup for cancelled or replaced images.
- Made themes update live and consistently across the app.
- Stopped OLED black mode from nudging pages downward while keeping its true-black surfaces.
- Made Home, Analytics, charts, tutorial examples, and Budster share the exact selected gauge colours.
- Darkened the default neutral yellow so it stays visible in Light mode without turning brown.
- Kept the full theme wardrobe: Budget Buddy Light, Dark, Material You, OLED black, Custom colours, and a colour-blind-accessible gauge palette.
- Rechecked budget rebuilding, zero/over-budget analytics, transaction drafts, currencies, achievements, and both side-by-side package identities.
- Tightened the offline boundary: no network permission, no cloud backup, no cleartext traffic, no exported internal screens, no bundled secrets, and hardened local receipt handling.
- Documented every Kotlin class with its purpose, relationships, important shared behaviour, and start/end markers.

## Before you install

- Android 8.1 or newer is required.
- A fresh installation is recommended for 3.0 Stable.
- Camera permission is optional; manual entry and gallery selection still work if it is denied.
- Your data stays inside the selected edition's private Android storage. Uninstalling or clearing its app data removes it.
- Install only the APKs attached to this official release.
